# hodor_group (Resource)

A group of the workspace's members, which contracts serve. Its members are `hodor_group_membership` resources, one per member: this resource neither lists nor manages them, but destroying the group removes its memberships with it. Import it by its id, `grp_...`.

## Example Usage

```terraform
resource "hodor_group" "platform" {
  name        = "Platform"
  description = "The platform team."
}
```

## Limitations

- The group's members are `hodor_group_membership` resources, one per member: this resource neither lists nor manages them. Destroying the group removes its memberships with it.
- A group the directory sync owns keeps its name: renaming it fails.

## Schema

### Required

- `name` (String) The group's name, 1 to 512 characters, not only spaces, unique in the workspace without regard to case. Changing it renames the group in place; a group the directory sync owns refuses a rename.

### Optional

- `description` (String) What the group is for, at most 2000 characters. Left out or empty, none. Changed in place.

### Read-Only

- `id` (String) The group's id, `grp_...`.

## Import

A group is imported by its id, `grp_` followed by 12 letters and digits, as Hodor answered it when the group was created: the `id` of the `hodor_group` in another state, for example. The Hodor app does not show it yet.

In Terraform 1.5 and later, with an [`import` block](https://developer.hashicorp.com/terraform/language/import):

```terraform
import {
  to = hodor_group.platform
  id = "grp_8fK2mQ9xLr4T"
}
```

Or with the [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
terraform import hodor_group.platform grp_8fK2mQ9xLr4T
```
