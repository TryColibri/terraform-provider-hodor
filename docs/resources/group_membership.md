# hodor_group_membership (Resource)

One member of a group: a member of the workspace, put in the group by their email. The person must already be a member of the workspace; they join it in the app, never through Terraform. Another member of the group is left as it is. A membership already there when it is created is taken over as it is, its configuration in the app kept. Import it by its group's id and the email, `grp_8fK2mQ9xLr4T/alice@example.com`.

## Example Usage

```terraform
resource "hodor_group" "platform" {
  name = "Platform"
}

# The person must already be a member of the workspace: people join it in the
# Hodor app, never through Terraform.
resource "hodor_group_membership" "alice" {
  group_id = hodor_group.platform.id
  email    = "alice@example.com"
}
```

## Limitations

- Terraform cannot add a person to the workspace. Someone who is not a member yet joins in the Hodor app first; until then the apply fails on `email`.
- Hodor matches the email without regard to case. A change of case alone changes nothing in Hodor, and the state keeps the configuration's spelling.
- The members of a group the directory sync owns are the directory's: adding someone to it, or removing someone from it, fails with `403`. Manage them in the identity provider.

## Schema

### Required

- `email` (String) The member's email, matched without regard to case or surrounding spaces. Changing it replaces the membership; a change of case or spacing alone changes nothing in Hodor.
- `group_id` (String) The group's id, `grp_...`, e.g. `hodor_group.x.id`. Changing it replaces the membership.

## Import

A membership is imported by its group's id and the email, joined by `/`: `<group id>/<email>`, the group's id `grp_` followed by 12 letters and digits, as Hodor answered it when the group was created.

In Terraform 1.5 and later, with an [`import` block](https://developer.hashicorp.com/terraform/language/import):

```terraform
import {
  to = hodor_group_membership.alice
  id = "grp_8fK2mQ9xLr4T/alice@example.com"
}
```

Or with the [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
terraform import hodor_group_membership.alice 'grp_8fK2mQ9xLr4T/alice@example.com'
```
